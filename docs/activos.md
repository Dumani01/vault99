# Referencia y activos

La referencia de diseño es el video aportado por el usuario. Se recrean el fondo oscuro, la silueta protagonista, la plataforma iluminada, las piezas laterales y la navegación horizontal. No se dispone del código ni de modelos 3D originales: el resultado usa ilustración 2D con transición y control de inclinación, no una rotación 360° de un objeto 3D.

assets/sneaker-blue.png fue generado para este proyecto como sneaker conceptual original sin logotipos. Se conserva únicamente como respaldo si falla una imagen. No representa fotografías oficiales de Nike, Louis Vuitton, Supreme, Off-White ni Dior. El catálogo incorpora ocho fotografías diferentes descargadas en public/assets, sin filtros que alteren sus colores. Las páginas de origen y las URL de descarga constan en imagenes-productos.json. Las fotografías pertenecen a sus respectivos titulares; no se declara una licencia comercial.

Las fuentes DM Sans y Space Grotesk se solicitan a Google Fonts; si no hay internet se utilizan Arial y fuentes del sistema. El sitio y el inventario funcionan sin ese servicio externo.
